## About FolderMonitor

FolderMonitor is a command-line program to propagate changes to files and folder to cloud storage.  
It is a feature-rich alternative to cloud vendors' web storage applications.  


FolderMonitor has powerful cloud equivalents to the unix commands rsync, cp,
mv, mount, ls, ncdu, tree, rm, and cat. FolderMonitor's familiar syntax
includes shell pipeline support, and `--dry-run` protection. It is
used at the command line, in scripts or via its [API](/rc).

Users call FolderMonitor *"The Swiss army knife of cloud storage"*, and
*"Technology indistinguishable from magic"*.

FolderMonitor is widely used on Linux, Windows and Mac. Third-party
developers create innovative backup, restore, GUI and business
process solutions using the FolderMonitor command line or API.


## What can FolderMonitor do for you?

FolderMonitor helps you to monitor changes to files or subfolders of a monitored folder and propagate those changes to a destination cloud storage or shered folder.
The application works on Windows and Linux.

- Script folder_monitor.py
    Script folder_monitor.py monitors a single folder.
- Script folder_monitor_batch.py
    Script folder_monitor_batch.py starts a monitor for each line in file monitor_entries.txt




## Features

* Monitor changes on a folder and propagate those changes to a cloud provider or shared folder
* Start a batch of monitors configured in a configuration file
* Test a single batch entry
